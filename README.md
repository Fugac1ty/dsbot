# DSBot · 情感陪伴机器人

> **不是「把大模型接进 QQ」的机器人框架，而是给模型一个身份。**
> 一套会遗忘的记忆、一份自己的作息、两只手（QQ / B站）、一张桌面上的分身，
> 和一个会主动想起你的目的机制。

DSBot 是一个**跑在你自己电脑上**的本地 AI 陪伴系统，以 [DeepSeek Harness](https://github.com/deepseek-ai)（DSH）
插件的形式存在。她有自己的 QQ 号，会像一个群友那样看消息、决定要不要说话、说完判断「这段可以结束了」；
有自己的 B站 账号和作息，会刷视频、评论、发动态；记得住也忘得掉；想找你的时候会主动来找你。

| | |
| --- | --- |
| 形态 | DSH 插件集合 + 独立 QQ 桥接进程，本地部署、单机运行 |
| 载体 | QQ（SnowLuma2 / 任意 OneBot v11）· B站 · 桌面桌宠 · 语音 |
| 组成 | **8 个可独立安装、独立停用的功能模块** + 工程文档 |
| 数据 | 全部留在本机（默认 `~/.dsh/dsbot/`），仓库里不含任何真实数据 |
| 许可 | MIT（SnowLuma2 是第三方专有运行时，**不随本仓库分发**） |

## 一、她能做什么

| 身份 | 能力 |
| --- | --- |
| **QQ 群友** | 群/私聊收发、引用回复、分条、表情包、图片/动图、语音、拍一拍、合并转发展开、上线补历史、提问与审批回传、四种运行模式 |
| **B站 用户** | 扫码登录、看视频打分收藏、评论与回帖、发四类动态、定时分享、私信、直播间监听、按自己的作息和每日额度行动 |
| **有记忆的人** | 衰减记忆卡（会模糊、会遗忘、有容量告警）+ 全量卡（只存档、永不改），QQ / B站 / 桌宠 三个场景共享同一张卡；遇事双向脱敏、身份对齐 |
| **有心情的人** | 被夸、被凶会推动心情，按半衰期回到平常；心情会影响回复快慢、发表情与语音的概率、插话积极程度 |
| **会主动找你** | 目的机制：从近期记忆里提炼「我想弄明白 / 想做点什么」，在安静时段外、额度内、你不在忙的时候，选 QQ 或桌宠来找你 |
| **桌面分身** | Electron 桌宠，文本 / 语音对话、气泡回复、专注模式；她的话在气泡上都有「回复」按钮 |
| **会说话** | 本地 GPT-SoVITS / 云端声音复刻 / 语音包，角色音色绑定，音量响度与频率上限可配（**AI 发语音默认关闭**） |
| **有钱包概念** | 每日 token 额度（QQ / B站 / 其他 / 总额，双单位），峰谷计价，80% 提醒、100% 停 |

> 她**不做**：不代你登录、不扫码、不绕过平台风控；不做多用户；不把控制台暴露到本机之外；
> 不删除任何不可恢复的数据（清理先隔离到 `_backups/`）。

## 二、架构

两套进程，一个身份：

```
┌──────────────── 你看到的 ────────────────────────────────┐
│  DSH Web GUI（8 个设置栏目）   控制台 :3100   桌宠窗口      │
└──────┬──────────────────┬─────────────────┬──────────────┘
┌──────▼──────────────────▼─────────────────▼──────────────┐
│  DSH 宿主                                                  │
│  ┌──────────── 8 个功能模块插件（各自独立）──────────────┐  │
│  │ 核心 配置/诊断/更新 · 角色 · 记忆 · 额度               │  │
│  │ B站 调度 · QQ 桥接 · 桌宠 · 语音                      │  │
│  └───────────────────────────────────────────────────────┘  │
└──────┬────────────────────────────────────────────────────┘
       │ HTTP（会话 Cookie）+ 子进程管理
┌──────▼────────────────────────────────────────────────────┐
│  QQ 桥接进程（单实例）：OneBot WS/HTTP · DSH 客户端 · 控制台   │
└──┬────────────┬──────────────┬────────────────────────────┘
   │ WS         │ stdio        │ HTTP
┌──▼────────┐ ┌─▼──────────┐ ┌─▼─────────────────────┐
│ SnowLuma2 │ │ DSH MCP    │ │ 语音引擎 8765 / 8767   │
│（第三方）  │ │ 客户端      │ │（local / cloud）        │
└───────────┘ └────────────┘ └───────────────────────┘
```

- **两套状态根**：桥接数据在仓库内 `state/`，插件数据在 `~/.dsh/dsbot/`。
- **三份配置**：`config.json`（QQ）、`~/.dsh/dsbot/config.json`（合体层）、`bili.config.json`（B站）。
- **DSH 端口会漂移**：桥接与插件都用 `discoverDshBaseUrl()` 发现，不硬编码。
- **工具面 fail-closed**：群友会话里的本地工具全部被 restrict，白名单之外什么都调不到。

## 三、8 个功能模块

每个模块是一个独立的 DSH 插件，只依赖包内文件 + Node 内置 + 自己声明的 npm 依赖。
安装后设置里出现 8 个并列栏目，可以单独安装、单独停用。

| 模块 | 负责 |
| --- | --- |
| [核心](dsbot-core/) | 配置模型与读改写、管理员身份投影、概览/诊断、全部参数、扩展宿主、平台注册表、组件更新、备份、日志 |
| [QQ](dsbot-qq/) | 桥接进程启停/自愈/日志/状态、模式切换、白名单/黑名单、SnowLuma 检测与启动、鱼群保护 |
| [B站](dsbot-bili/) | 生物钟（五条 tick）、B站 配置与扫码登录、养鱼参数、观看历史、口味扫描、定时分享与四类动态、鱼群守则 |
| [记忆](dsbot-memory/) | 衰减记忆卡（维护/压缩/备份/注入块渲染）、双向脱敏记忆、身份对齐、隐私闸门、主人特权审计 |
| [角色](dsbot-character/) | 角色包创建/切换/存档/回档/删除、人格卡解析与编辑、角色迁移与指针、自我认同 |
| [额度](dsbot-token/) | 每日 token 额度与用量采集（四口径）、峰谷计价、80%/100% 闸门、启动回填 |
| [桌宠](dsbot-pet/) | 桌宠安装/更新/启停/卸载、桌宠对话、目的机制的桌宠载体、`pet/host.json` 心跳 |
| [语音](dsbot-voice/) | 语音包安装/启停/健康检查、TTS 路由（本地/云端/Piper）、角色音色、云端凭据 |

**模块之间的三条约定：**

1. **自包含** —— 每个模块只能 import 包内文件、Node 内置模块和自己 `package.json` 里声明的依赖，
   不允许跨模块引用；由 `tools/test-harness.mjs` 的 `checkPackage()` 自动检查。
2. **配置互通** —— 8 个模块共用一套跨进程配置锁 + 原子写 + 自动备份，每个键只有一个写者，
   同时改配置不会互相覆盖。
3. **互不依赖** —— 任何一个模块都可以单独停用，停用只影响它自己的设置栏目和后台任务，
   其余模块照常工作。

每个模块目录内部结构一致：

```
<模块>/
├── package.json          # dsh.bundle.patch + dsh.client.platform=web
├── cordis.patch.yml      # insert 一行：id=<模块>
├── icon.svg              # 插件列表图标（每个模块不同色）
├── locale/{zh,en}.json   # 插件名与描述
├── lib/

│   ├── config-lock.js    # 跨模块配置锁 + 原子写 + 备份
│   ├── index.js          # 宿主入口：export name/inject/apply/default
│   ├── client.js         # 浏览器半边：window.__ModuleLoader__.load(...)
│   └── vendor/           # 三方与公共代码副本

└── PLAN.md               # 各模块的实现清单与进度
```

## 五、快速开始

**前置**：Windows 10/11 · Node ≥ 22.13 · DeepSeek Harness（能正常打开 Web GUI）· SnowLuma2（第三方，自己去官方
Releases 下载并扫码登录——本项目不下载、不打包、不代同意协议）。

```bash
# 取代码
git clone https://github.com/Fugac1ty/dsbot.git
cd dsbot

# 全量体检：模块清单 + 自包含检查 + 每个模块的冒烟测试（离线，不连 QQ、不写真实 ~/.dsh）
node tools/verify-all.mjs

# 单个模块冒烟
node dsbot-token/scripts/test-smoke.mjs
```

挂进 DSH 的步骤（preset / MCP / bundle 注册、profile 归属、共存冲突与回滚）见
[docs/MIGRATION.md](docs/MIGRATION.md)。

## 七、安全与边界（摘要）

- **群友碰不到你的机器**：仿真会话的工具面是白名单，fail-closed，本地执行能力全部 restrict。
- **发送必须命中白名单**：没有「管理员例外」这种后门；白名单为空 = 谁都不响应。
- **控制台只接受本机回环** + 令牌（定长比较）+ Host/Origin 校验 + 写操作强制 JSON。
- **密钥不落日志**；状态目录切断 ACL 继承。
- **不可逆删除 = 事故**：清理一律先隔离到 `_backups/`。
- 不承诺提示注入在语义层 100% 防护——真正的边界是工具面与白名单。
